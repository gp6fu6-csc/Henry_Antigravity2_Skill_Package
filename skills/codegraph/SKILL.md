# CodeGraph: Semantic Code Intelligence for AI Coding Agents

> **The fastest complete code graph · surgical context · built for how agents actually work · 100% local**

`codegraph` is a local-first code intelligence engine, CLI, and MCP server powered by a Rust kernel, Tree-sitter AST extraction, and SQLite (FTS5). It delivers exact architectural graphs and symbol relationships without LLM hallucinations or massive token context consumption.

---

## 1. Why Agents Use CodeGraph

- **Zero Hallucination**: Dependencies, types, and call paths are extracted directly from Tree-sitter ASTs, not generated by an LLM.
- **Surgical Context**: Instead of stuffing 20 full files into context, CodeGraph returns only the relevant symbol signatures, callers, callees, and cross-file edges.
- **Bi-directional Traversal**: Effortlessly trace upstream callers (`who calls this function?`) and downstream callees (`what does this method trigger?`).
- **Complete Local Privacy**: Runs 100% on the local machine; all index data resides in `.codegraph/`.

---

## 2. Core CLI Commands

### Project Initialization & Status
```bash
# Build/update the AST index for the current repository (creates .codegraph/)
codegraph init

# View indexing statistics (nodes, edges, files, languages, index staleness)
codegraph status

# Unlock index if a previous indexing process crashed
codegraph unlock
```

### Exploration & Surgical Retrieval
```bash
# Explore relevant symbols, definitions, and call paths in one shot
# (Matches the codegraph_explore MCP tool output)
codegraph explore <natural language query or symbol>

# Inspect a single symbol's AST details and direct callers, or read a file with line numbers
codegraph node <symbol_name | path/to/file>

# Search symbols across the codebase with filters
codegraph query <search_term> --kind function|class|interface --limit 20

# Trace what calls a specific function/method across the entire repo
codegraph callers <function_or_method_name>

# Trace what a specific function/method calls
codegraph callees <function_or_method_name>

# Display hierarchical file structure
codegraph files [path] --max-depth 3
```

---

## 3. MCP Integration

CodeGraph provides an MCP server interface that seamlessly hooks into Antigravity:
- **`codegraph_explore`**: The primary exploration tool for an agent to answer architectural queries.
- **`codegraph_node`**: Fetches detailed AST node metadata and direct caller chains.
- **`codegraph_callers`**: Queries all inbound call edges.
- **`codegraph_callees`**: Queries all outbound call edges.
- **`codegraph_query`**: Symbol search across indexed files.

To register the MCP server with Antigravity:
```bash
codegraph install
```
This automatically wires the CodeGraph MCP server into your agent configuration.

---

## 4. Best Practices for Coding Agents

1. **Query Before Grepping**: When understanding an unfamiliar codebase, use `codegraph explore <concept>` or `codegraph callers <func>` first before running brute-force grep or reading dozens of files.
2. **Impact Analysis Before Refactoring**: Before changing a function signature or removing an exported symbol, run `codegraph callers <symbol>` to find every call site that needs updating.
3. **Verify Staleness**: If multiple edits have occurred, check `codegraph status` or re-run `codegraph init` (or incremental index) to ensure the graph reflects the latest edits.
