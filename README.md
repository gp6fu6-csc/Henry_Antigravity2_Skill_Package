# Henry Antigravity 2.0 Skill Package

This repository contains custom Agent Skills and Plugins for Google Antigravity 2.0.

## Included Skills

### 1. `project-report-doctomd`
- **Description**: Comprehensive skill for converting research project documents (Word/PDF proposals, interim reports, final reports, results, shortnotes, and PowerPoint presentations) into structured Markdown files with figure image extraction.
- **Path**: `plugins/project-report-doctomd/` and `skills/project-report-doctomd/`
